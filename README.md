# ac3ds-workspace

『とびだせ どうぶつの森』（3DS・日本版）と『どうぶつの森 ハッピーホームデザイナー』の解析を、複数の AI エージェントで進めるための作業場です。

- 解析の記録とシンボルは [ac3ds-re](https://github.com/yak9909/ac3ds-re) にあります。
- このリポジトリには、作業場の構成、エージェントの規則（AGENTS.md・CLAUDE.md・スキル）、作業を回す道具（`scripts/`）だけを置きます。

## 構成

| 場所 | 内容 |
|---|---|
| `AGENTS.md` / `CLAUDE.md` | 全エージェント共通の規則 / Claude Code 用の規則 |
| `skills/` | オーケストラ（作業を割り振り、結果を判定する役）の手順 |
| `.claude/agents/` | Claude のワーカーの定義 |
| `templates/` | ワーカーへの依頼文の雛形 |
| `scripts/` | 準備・監査・作業を回す道具 |
| `workspace.toml` / `workers.toml` | 作業場の構成 / ワーカーの設定 |
| `ac3ds-re/` など | 各リポジトリ（このリポジトリには含まれない） |
| `_local/` | Git に入れない物（ROM・IDB・作業ツリーなど。このリポジトリには含まれない） |

## 準備

1. このリポジトリを clone する。
2. `scripts/bootstrap.ps1` を実行する（各リポジトリの clone、`_local/` の作成、外部ツールの取得）。
3. ゲームのデータは含みません。自分で吸い出した物を `_local/builds/` に置きます。
