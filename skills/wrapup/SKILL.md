# 中断

1. 新しい依頼を出さない（その提供元のワーカーについて）。Codex の使用率が取れない間は、上限に達したエラーを合図にする。
2. 動いている `orch.py claude`・`orch.py codex` は、利用枠の上限で自動で止まる。上限の前に止める時は、起動したバックグラウンドのシェルを止める（続きは `--resume`）。80% を超えても、もう出たワーカーの結果の判断はしてよい。
3. 報告がそろったら `python scripts/orch.py wrapup` を実行する（全ての作業ツリーの試行を保存して push し、引き継ぎメモを書く）。引き継ぎメモには次の1手だけを書き、決まりは書かない。結論は設計書か topics に書いて渡す。
4. 利用者に、止めた作業・次の1手・利用枠のリセット時刻を伝える。

**再開**: 新しいセッションで `orch.py start` を実行し、引き継ぎメモを読む。ただし直しは、文脈が大きい時や間が空いた時は、新しいセッションで差分と指摘だけを渡して頼む（スキル `dispatch`）。
